# Munim

Seller negotiation agent for AgentX Challenge 2, Round 1.

Implementation is awaiting the official starter kit and Rezolve documentation. The repository currently contains the supplied build specification and the outstanding input checklist; it does not yet contain a working agent.

- [Build specification](docs/BUILD_PROMPTS.md)
- [Required inputs and open questions](docs/OPEN_QUESTIONS.md)

Place the official starter kit in `starter/` and the TraceWare and managed knowledge retrieval reference documents in `docs/rezolve/`. Keep secrets in an untracked `.env` file. Implementation must follow the specification in order, starting with a contract quoted from the starter code.
