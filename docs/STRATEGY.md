# Cheap talk is free, commitments are priced
The firewall removes pressure before either brain sees input. It verifies catalogue facts and extracts a narrow basket grammar. Raw buyer text never enters the voice prompt.

The ladder opens at list. Only changed commitments unlock quantity/bundle discounts. Same needs retain the previous price. The baseline instead concedes with time; both respect the gate and deadline. Tuning chooses the measured winner and reports the trade-off.

Every outward offer, including acceptance, is gated. Exceptions become terminal walk-away moves. Voice validation allows exact safe English/Hinglish templates only, retries optional LLM phrasing once, then uses the template. This deliberately conservative policy rejects every novel claim.

The seller does not reveal cost, floor or buffer. Private shopkeeper diagnostics expose these for demonstration, never as buyer-facing speech. Mock verification is local behavior, not provider compliance.
